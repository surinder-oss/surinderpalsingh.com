# surinderpalsingh.com

Personal site of Surinderpal Singh, mortgage broker in Calgary and founder of Gold Lion Mortgages Inc.

- Plain static HTML, hosted on GitHub Pages
- Custom domain set in `CNAME`; DNS at Porkbun
- Edit `index.html` and push to `main` to update the live site

## Old page redirects

The `*.html` files other than `index.html` and `404.html` redirect old Mortgage Centre addresses (for example `/contact-us`, `/mortgage-calculators`) to the matching section of this site or to goldlionmortgages.com, so old Google links keep working. Anything else lands on `404.html`, which sends visitors home.
